
unbuild tool selected (highest-priority hint)
    = "Sélectionnez les objets à démonter" / "Select the objects to dismantle"
                                                            [tutorial.unbuild_selection]

water reserve empty
    = "Rechargez votre eau !" / "Refill your water !"      [tutorial.refill_water]
    (only hint allowed to stay visible during the NIGHT)


day 1 + seeds > 0  +  gardening tool NOT equipped
    = "Equipez la pelle pour planter des roses" / "Buy roses with the GARDENING tool"
                                                            [tutorial.buy_roses]

day 1 + seeds > 0  +  gardening tool equipped
    = "Plantez des roses" / "Plant roses"                   [tutorial.plant_roses]

day 2+ + seeds > 0, whatever is equipped
    = "Plantez des roses" / "Plant roses"                   [tutorial.plant_roses]
    (the "equip the pelle" step is gone from day 2 on: the player knows the tool.
     Plays once per day — planting the first rose of the day drops the step for the
     rest of that day even if seeds remain, and the next hint takes over)

planted roses still dry (unwatered > 0)
    = "Arrosez vos roses" / "Water your roses"              [tutorial.water_roses]

day 1 + all roses watered + pasteque remaining
    = "Plantez une pastèque pour irriguer davantage de terre sèche"
      / "Plant a watermelon to irrigate the soil"            [tutorial.plant_pasteque]

day 1 + all roses watered + turret_epine remaining
    = "Plantez des cracheuses pour défendre le jardin"
      / "Plant spitters to defend the garden"                [tutorial.plant_turret_epine]

day 1 + ready to end day + fewer planted roses than the clients the planificator previews for tomorrow
    = "Plantez suffisament de roses pour satisfaire vos clients du lendemain"
      / "Plant enough roses to satisfy tomorrow's clients"   [tutorial.plant_more_roses]
    -> arrow points right at the planificator; withholds the "pass the night" prompt
       until enough roses are planted

everything done (all watered, no day 1 pasteque/turret prompt remaining) + clients already served + any tantrum clients have vanished
    = "Passez la nuit" / "Pass the night"                   [tutorial.pass_night]
    -> turns into the hold-to-confirm prompt below
    (gated by can_start_night_after_clients() -> clients_finished_for_day(),
     which already requires the tantrum to be inactive with no hostiles left)

--- end-of-day HOLD prompt (replaces "pass the night") ---

ready to end day, keyboard
    = "Maintenir ESPACE pour démarrer la nuit" / "Hold Space to start the night"
                                                            [tutorial.hold_start_night_space]

ready to end day, gamepad
    = "Maintenir X pour démarrer la nuit" / "Hold X to start the night"
                                                            [tutorial.hold_start_night_pad]

--- contextual BUILD alerts (3s, while placing a building anywhere in day) ---

placing a plant/turret on non-grass tile

placing on a floor you can't build on

 NIGHT (monsters attack)  —  most hints hidden, only water-empty shows

night spawner-reveal cutscene begins (camera pans to devil spawners)
    = "les diables ont faim !" / "devils are hungry !"      [tutorial.devils_hungry]

night starts with no roses/counter stock for monsters
    = "La nuit est calme sans roses ..." / "The night is calm without roses ..."
                                                            [tutorial.calm_night_no_roses]


========================================================================
 BIG BUCKET 2 — "NIGHT AFTER" (dawn -> the following day)
 After the night: sun rises, roses grew, you harvest + sell.
========================================================================

--- DAWN transition (night just ended, new day still growing) ---

sunrise transition, no phase started yet
    -> no hint shown (label stays blank until the morning phase begins)

--- MORNING harvest phase ---

never placed a rose_shop_counter yet + client sale not started
    = "Construisez un comptoir de vente de roses" / "Place the Shop"  [tutorial.place_shop]
    (one-time step: dawn only, before the client phase — so first seen on day 2.
     It never returns once the first counter is placed, and the afternoon build
     phase never raises it.)

no grown-up roses to sell
    = "Pas de roses, pas de clients aujourd'hui" / "No roses, No clients today"
                                                            [tutorial.no_roses_no_clients]
    (client sale is skipped automatically; no hold-to-start-clients prompt)

grown-up roses ready + counter has room
    = "Cueillez vos roses" / "Harvest your roses"           [tutorial.harvest_rose]

grown-up roses ready + counters all full + at least one counter already built
    = "Comptoirs remplis ! Ajoutez des comptoirs pour vendre vos roses"
      / "Add counters to sell your roses"                   [tutorial.add_counters_to_sell_roses]
    (counters full but NONE built yet -> "Place the Shop" instead)

grown-up roses exist -> can skip harvest straight to clients (HOLD), keyboard
    = "Maintenir ESPACE pour faire entrer les clients" / "Hold Space to let clients come in"
                                                            [tutorial.hold_start_clients_space]
same, gamepad
    = "Maintenir X pour faire entrer les clients" / "Hold X to let clients come in"
                                                            [tutorial.hold_start_clients_pad]

--- CLIENT sale phase ---

client reveal cutscene begins (camera pans to client entrances)
    = "les clients viennent acheter des roses" / "clients are coming to buy roses"
                                                            [tutorial.clients_coming]

clients are actively buying
    -> no hint shown (only water-empty and the tantrum alert may appear)

rose shortage -> clients turn hostile (PERSISTENT red alert, shows count)
    = "Pénurie de rose : des clients sont enragés" / "Rose shortage: clients are enraged"
                                                            [tutorial.tantrum]

a crushing people-agent (client / merchant / builder) crushes anything by walking on it
    = "Les gens écrasent vos plantes !" / "People are trampling your plants!"
                                                            [tutorial.people_crush_plants]
    (transient 3s alert. Pops once per burst: further crushes are ignored while it is
     still showing, and it can pop again after it vanishes. Skipped entirely while any
     other alert holds the label, so it never hides the persistent tantrum alert.
     Monsters crushing plants never raise it — that is normal night gameplay.
     Sheep crush nothing at all, so they never raise it either.

     Crush rule (AgentTileInteractionController.VILLAGER_CATEGORIES — a "people agents that
     crush" grouping, broader than a "villager"/house resident since it includes clients):
       people (clients/merchants/builders) -> plants (roses + imperials), pasteques, turrets. All of them.
       monsters   -> pasteques, and turrets flagged eatable_by_monsters (with eat pause).
       sheep      -> nothing.)

game over reached (shown by game_over modal, not the hint label)
    = "Game Over" / "Game Over"                             [tutorial.game_over]
