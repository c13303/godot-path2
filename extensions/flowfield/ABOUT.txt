CPP Godot Extension: Flow Field / A*
====================================

This is Rabbit Game's current native extension source. It contains reusable algorithms, but the
folder and DLL are not yet a portable drop-in library: generic navigation, Godot adaptation, Rabbit
Game phases/debug APIs, damage/AoE behavior, and projectiles are currently built together.

Read README.md in this directory for reuse instructions and ../../MIGRATION.md for the reviewed
standalone-repository, compatibility, extraction, testing, and demo plan.

Important: moving this folder to another repository does not by itself make it reusable. Preserve
Rabbit Game's current API and behavior through documented host-side compatibility wrappers while
the game-neutral core and Godot adapter are extracted.
